# Дизайн система

Версия 0.1 (Фаза 0). Реализира се във Фаза 1 като маршрут `/design` с всички компоненти
в трите теми, преди да се правят екрани.

## 1. Принципи
1. **Работен инструмент за 8 часа на ден:** плътно, спокойно, бързо. Без анимации над
   120 ms, без декоративни елементи.
2. **Клавиатурата е първа:** всяко действие има клавиш, а фокусът винаги се вижда.
3. **Числата са главните герои:** табличните цифри (tabular-nums) са подравнени вдясно и
   отрицателните се виждат веднага.
4. **Контекстът винаги се вижда:** текуща фирма, период, отчетна валута (BGN/EUR) и дали
   периодът е заключен.
5. **Грешките казват какво и как:** „ДДС номерът BG12345 не е валиден във VIES към
   14.11.2026. Провери номера или запиши контрагента като нерегистриран.“

## 2. Токени

Всички цветове минават през семантични CSS променливи. В компонентите няма твърди цветове
(ESLint/Stylelint правило забранява hex/rgb извън файла с темите).

| Токен | Употреба |
|-------|----------|
| `--surface` | Основен фон |
| `--surface-raised` | Панели, таблици, диалози |
| `--surface-sunken` | Полета за въвеждане, редове през един |
| `--surface-selected` | Избран ред/клетка |
| `--text` | Основен текст |
| `--text-muted` | Помощен текст, етикети |
| `--border` | Граници на панели и таблици |
| `--border-strong` | Граници на активния панел |
| `--focus` | Пръстен на фокуса (2 px, винаги видим) |
| `--accent` / `--accent-text` | Основно действие, връзки |
| `--positive` | Успех, кредитно салдо (по избор) |
| `--negative` | Грешка, отрицателни суми |
| `--warning` | Предупреждение, незаключен минал период |
| `--locked` | Заключен период |

- **Тъмна:** тъмносиви повърхности, без чисто бяло (намален контраст за дълга работа).
- **Черна:** истински #000 за OLED. Панелите се разделят с ясни граници (`--border`),
  а не с нюанси на фона.
- Тест в CI изчислява контраста на всички двойки текст/фон и проваля build-а под 4,5:1
  (3:1 за граници на полета и за фокуса).

### Типография
- Шрифт: **Inter** (поддържа кирилица), самостоятелно хостван. Числата с
  `font-variant-numeric: tabular-nums`. Резервен: system-ui.
- Размери: 13 px основен в таблиците, 14 px в формите, 12 px помощен, 16/20 px заглавия.
  Височина на ред в таблица: 28 px (плътно) или 32 px (нормално), по избор на потребителя.

### Пространство и форма
Скала 4 px (4, 8, 12, 16, 24, 32). Радиус 4 px. Сенки само за диалози и падащи менюта.

## 3. Компоненти (всички в `/design`, в трите теми)

| Компонент | Особености |
|-----------|------------|
| Обвивка на приложението | Горна лента: фирма, период, валута, заключване; лява навигация (сгъваема); лента за състояние долу (клавишни подсказки) |
| Командна палитра (Ctrl+K) | Фирми, сметки, контрагенти, документи, справки, действия; размито търсене на кирилица и латиница |
| Превключвател на фирма | Ctrl+Shift+K; последните фирми първи |
| Таблица за данни | Виртуализирана (100 000+ реда), сортиране, филтри, избор на колони, замразени колони, експорт на видимото |
| Таблица за въвеждане („като Excel“) | Enter/Tab напред, Shift+Tab назад, стрелки, F2 редакция, Ctrl+D копира реда отгоре, Ctrl+Enter запис |
| Поле за сума | Български формат 1 234,56; приема запетая и точка; пресмята прости изрази (`=120*1,2`) |
| Поле за дата | „15“ = 15-о число на текущия период; „1511“ = 15.11; „+1“ = утре; dd.mm.yyyy |
| Автодовършване на сметка/контрагент | По код или име, кирилица и латиница; показва аналитичностите на сметката |
| Бутон, връзка, поле, избор, отметка, радио | Radix примитиви + токени |
| Диалог за потвърждение | За опасни действия; изисква въвеждане на дума при необратими действия |
| Съобщения (toast) | Не крадат фокуса |
| Празно състояние | Обяснява следващата стъпка и нужния клавиш |
| Значки за състояние | Чернова, осчетоводен, сторниран, заключен |
| Списък с грешки при валидиране | Всяка грешка е връзка към документа/полето |

## 4. Клавиши

**Ограничение на браузъра:** някои комбинации не могат да се прихванат (Ctrl+N, Ctrl+T,
Ctrl+W, F11, F12 в Chrome), а други не бива (F5 презарежда, F3/Ctrl+F търси, F6 е
адресната лента). Затова ползваме F2, F4, F8, F9, F10 и комбинации с Alt/Ctrl. Във Фаза 1
тест в Chrome, Edge и Firefox проверява, че всяка комбинация работи.

| Клавиш | Действие |
|--------|----------|
| Ctrl+K | Командна палитра |
| Ctrl+Shift+K | Смяна на фирма |
| Alt+P | Смяна на период |
| Alt+T | Смяна на темата (светла → тъмна → черна → системна) |
| ? | Страница с всички клавиши |
| F2 | Нов документ / редакция на клетка |
| F4 | Отваря списъка за избор (сметка, контрагент) |
| F8 | Сторно на избраната статия (с потвърждение) |
| F9 | Преизчисляване/проверка (напр. ДДС на документа) |
| Ctrl+Enter | Запис |
| Esc | Отказ / затваряне |
| Ctrl+D | Копира предходния ред |
| Alt+↓ | Слизане от число в справка към документите |
| Alt+← | Назад |
| g, после буква | Бърза навигация (g d = документи, g j = журнал, g t = оборотна ведомост) |

Пълният списък се генерира от един регистър на клавишите (`packages/ui/shortcuts.ts`).
Страницата „?“ и подсказките в лентата за състояние идват от същия регистър.

## 5. Формати
- Числа: `1 234,56` (тесен неразделящ интервал за хилядите, запетая за десетичния знак).
  При въвеждане се приемат и `1234.56`, и `1 234,56`.
- Дати: `dd.mm.yyyy`.
- Валута: кодът е след сумата (`1 234,56 EUR`). В справките за години в BGN се показва BGN.
